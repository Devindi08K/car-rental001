Use these exact filenames and dimensions. Export as JPG or WebP. Keep subjects away from edges when possible and avoid watermarks, visible logos, number plates, and low-resolution assets.

## Brand and visual direction

- Premium black, charcoal, and electric-lime website palette
- Clean automotive photography
- Natural or studio lighting
- Keep the spotlight, rim light, or light beam focused on the vehicle—never on the background
- Create strong separation between the illuminated vehicle and the darker surroundings
- Low perspective for vehicles
- Sri Lankan locations only where location is relevant
- No text, graphic overlays, or fake pricing inside the images

## Easy upload workflow

Use the admin panel for photos that need to appear immediately:

1. Open `/admin/gallery` for wedding/general gallery images.
2. Open `/admin/vehicles/new` or a vehicle edit page for vehicle photos.
3. Drag and drop several JPG, PNG, or WebP files at once, or click the photo box and select multiple files.
4. The first vehicle photo becomes the main card image.
5. Use the left/right controls to change the vehicle photo order.

For the homepage hero only, continue using the fixed local file:

`public/photos/hero/hero-car.jpg`

For large batches, use the same folder structure in this guide, then tell the developer which files should become the fleet, service, wedding, or promotion cards.

## Submission checklist

- Export as JPG or WebP
- Use the exact filenames above
- Keep file size ideally below 1 MB by using WebP or optimized JPG
- Do not add visible brand names or watermarks
- Use the same vehicle paint, lens style, and lighting family across the fleet set
- Preserve privacy by avoiding real people, number plates, and identifiable locations unless authorized
